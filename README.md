# Локальний конвертер файлів

Скрипт зі звичайним вікном і CLI. Пакетом стискає скріншоти, зменшує роздільну здатність, конвертує PNG/JPG у WebP і перетворює PDF на Word (DOCX) — усе локально, без хмари.

## Швидкий запуск (Windows)

Після збірки двічі клацніть `dist\Converter.exe` — відкриється вікно, Python ставити не потрібно.

Зібрати exe ще раз:

```bat
build_exe.bat
```

## Встановлення з Python

Потрібен Python 3.10+.

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Або двічі клацніть `run.bat` — він сам створить середовище і відкриє вікно.

## GUI

```bat
run.bat
```

або

```bat
.venv\Scripts\python -m image_opt
```

У вкладці **Зображення** можна:

- додати файли або цілу папку
- обрати формат (`webp` за замовчуванням)
- виставити якість 1–100
- обмежити ширину/висоту (пропорції зберігаються)
- увімкнути рекурсію, WebP без втрат, скидання метаданих
- не зберігати файл, якщо він вийшов більшим за оригінал

Пресети:

- **скріншоти** — WebP, якість 82, без зміни розміру
- **агресивно** — WebP, якість 68, максимум 1920×1080

У вкладці **PDF → Word**:

- додати PDF або папку
- за потреби обмежити діапазон сторінок
- вказати пароль, якщо файл захищений
- отримати `.docx` у папці `converted`

Оригінали не змінюються.

## CLI: зображення

```bat
.venv\Scripts\python -m image_opt "D:\Screenshots" -o "D:\Screenshots\optimized" -f webp -q 80 -r
```

## CLI: PDF у Word

```bat
.venv\Scripts\python -m image_opt --pdf-to-word "D:\Docs\file.pdf" -o "D:\Docs\converted"
.venv\Scripts\python -m image_opt --pdf-to-word "D:\Docs" -r --start-page 1 --end-page 10
```

Корисні прапорці:

| Прапорець | Дія |
|---|---|
| `-o`, `--output` | Папка для результатів |
| `-f webp\|jpeg\|png\|keep` | Цільовий формат зображень |
| `-q 80` | Якість |
| `--max-width 1920` | Максимальна ширина |
| `--max-height 1080` | Максимальна висота |
| `-r` | Рекурсивно |
| `--lossless` | WebP без втрат |
| `--always-write` | Зберігати навіть якщо файл більший |
| `--overwrite` | Перезаписувати існуючі файли |
| `--replace` | Видалити оригінал після успішної обробки |
| `--pdf-to-word` | Конвертувати PDF у DOCX |
| `--start-page`, `--end-page` | Діапазон сторінок PDF |
| `--password` | Пароль до PDF |
| `-g` | Відкрити GUI |

Підтримувані зображення: PNG, JPG, JPEG, WebP, BMP, TIFF, GIF, ICO.

Скановані PDF без текстового шару конвертуються як зображення на сторінках Word.
